# Anomaly Log

Each anomaly is also a GitHub issue labelled `anomaly` (docs/VV_PLAN.md §6).
Severity: **Critical** (wrong metric values, data loss, silent failure),
**Major** (a requirement not met, workaround available), **Minor** (cosmetic
or usability). A release cannot ship with an open Critical or Major anomaly
without a signed risk acceptance.
