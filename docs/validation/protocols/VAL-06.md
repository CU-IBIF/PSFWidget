## 1. Objective

Show that representative users can complete a session analysis in the GUI quickly and without help.

## 2. Scope

3–5 users: facility manager, researcher, engineer.

## 3. Materials

A workstation with PSFWidget; the user manual; a bead file and profile; SUS questionnaire.

## 4. Method

Scripted tasks (think-aloud, observed, timed): open a file with a profile, fix a missing value, analyse, exclude a bead with a reason, record, write a report, approve it, find a session on the Levey-Jennings chart.

## 5. Acceptance criteria

Task completion ≥ 90%; session analysis ≤ 10 minutes (NFR-08); SUS ≥ 70.

## 6. Analysis

Completion, times, SUS score; usability issues logged as Minor anomalies (or higher if they cause wrong results).

## 7. Records

Test record, observation notes, questionnaires.

## 8. Deviations

Any deviation is recorded in the test record with its reason and impact and approved by the facility manager.
